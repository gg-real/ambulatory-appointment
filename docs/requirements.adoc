
= Требования информационной системы «Амбулаторный приём»
:toc:
:sectnums:

== Бизнес-требование

[#BR-01]
=== BR-01

Сократить случаи, когда пациенты приходят на отменённый приём, а освободившиеся интервалы остаются недоступными для повторной записи.

== Пользовательское требование

[#UR-01]
=== UR-01

Регистратор должен иметь возможность отменить выбранный приём и увидеть для него список пациентов с действующими записями, статус отмены и результат уведомления.

== Функциональные требования

[#FR-01]
=== FR-01

При отмене приёма система должна перевести все действующие записи пациентов на этот приём в статус «отменена», сформировать для них уведомления об отмене и освободить соответствующие интервалы расписания для новой записи.

[#FR-02]
=== FR-02. Согласованная обработка отмены

При отмене приёма компонент C-01 должен изменить статус всех действующих записей пациентов на «отменена» и передать в C-02 перечень затронутых пациентов, а в C-03 — идентификаторы соответствующих интервалов.

[#FR-03]
=== FR-03. Формирование уведомлений

Компонент C-02 должен сформировать по одному уведомлению для каждого пациента с действующей записью на отменённый приём. В уведомлении должны присутствовать фамилия или идентификатор пациента, врач, дата и время отменённого приёма и информация об отмене.

[#FR-04]
=== FR-04. Освобождение интервала

Компонент C-03 должен перевести интервал отменённого приёма в состояние «свободен» только после того, как отмена соответствующей записи зафиксирована в C-01.

[#FR-05]
=== FR-05. Фиксация результата операции

Компонент C-04 должен записывать в журнал каждую отмену приёма с указанием даты и времени операции, идентификатора приёма, пользователя, выполнившего отмену, количества затронутых записей и результата освобождения интервала.

== Нефункциональные требования

[#NFR-01]
=== NFR-01

После подтверждения отмены приёма система должна отобразить результат изменения статуса записей и доступности интервалов не позднее чем за 2 секунды в 95% операций при нагрузке до 30 операций отмены в минуту.

[#NFR-02]
=== NFR-02

Внешний сервис должен отвечать в установленный срок; при отсутствии ответа фиксируется тайм-аут.

[#NFR-03]
=== NFR-03

Освобождение интервала должно соответствовать подтверждённому результату отмены; при неподтверждённой отмене интервал остаётся занятым.

[#NFR-04]
=== NFR-04

Каждая операция отмены должна попадать в журнал с обязательными данными.

== Бизнес-правило

[#BP-01]
=== BP-01

После отмены приёма действующая запись пациента на этот приём не может сохраняться как активная, а освободившийся интервал не должен считаться занятым отменённой записью. Повторная запись на интервал разрешается только после фиксации его освобождения и при отсутствии других ограничений расписания.
