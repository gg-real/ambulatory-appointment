= Информационная система «Амбулаторный приём»
:toc:
:sectnums:

== Назначение комплекта

Комплект документации описывает проектируемую информационную систему «Амбулаторный приём» в части обработки отмены приёма.

Документация содержит требования системы, взаимодействия компонентов, описание программного интерфейса передачи уведомлений и пользовательского интерфейса регистратора.

Комплект предназначен для поддержания согласованности между требованиями и спецификациями интерфейсов.

== Границы комплекта

В комплект входят:

* xref:docs/requirements.adoc#BR-01[BR-01], xref:docs/requirements.adoc#UR-01[UR-01], xref:docs/requirements.adoc#FR-01[FR-01]–xref:docs/requirements.adoc#FR-05[FR-05], xref:docs/requirements.adoc#NFR-01[NFR-01]–xref:docs/requirements.adoc#NFR-04[NFR-04] и xref:docs/requirements.adoc#BP-01[BP-01];
* программный интерфейс IF-01;
* пользовательский интерфейс UI-01.

За границами комплекта находятся реализация программного кода, конкретные технологии хранения и передачи данных, внутреннее устройство внешнего сервиса A-03 и отдельные интерфейсы пациента и врача.

Исходные документы представлены в формате AsciiDoc.

Сборка выполняется из корня репозитория:

----
asciidoctor -D build README.adoc
----

Для сборки отдельных документов используются соответствующие
исходные файлы `.adoc`.
